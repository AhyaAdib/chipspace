# ChipSpace

ChipSpace is an engineering learning and development workspace focused on digital design, RTL, computer
architecture, AI accelerators, FPGA implementation, verification, and ASIC physical design.


## Environment
- OS: Windows 11
- Linux: WSL 2 Ubuntu 24.04
- Editor: Neovim
- Repository: GitHub
- Workspace: /mnt/d/ChipSpace

## Repository Structure
- docs/: Competition and engineering documentation
- learning/: Structured technical learning
- projects/: Practical implementations
- daily-reports/: Daily learning records
- weekly-reports/: Weekly learning records
- experiments/: Engineering experiments
- scripts/: Automation

## Learning Philosophy
Understand => Calculate => Model => Implement => Verify => Measure => Optimize => Document
