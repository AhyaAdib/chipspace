# Git Fundamentals

## 1. Git vs GitHub

- Git: Local version control system.
- GitHub: Remote repository hosting platform.

## 2. Git Workflow

1. Working directory
2. Staging area
3. Local repository
4. Remote repository

## 3. Essential Commands

| Command | Purpose |
|---|---|
| git status | Inspect working tree |
| git add | Stage changes |
| git diff | Inspect unstaged changes |
| git diff --cached | Inspect staged changes |
| git commit | Save local snapshot |
| git push | Upload commits |
| git pull | Fetch and integrate remote changes |
| git log | Inspect commit history |

## 4. Engineering Workflow

Write → Inspect → Stage → Review → Commit → Push
